# Finance Landing Page

## Project Overview

This project is a static website created for a real business as part of my full-stack development journey. The project is currently built with HTML5 and CSS.

The initial goal is to build a clean, responsive, and accessible front-end without relying on frameworks or JavaScript. Once the static version is complete, it will be deployed using GitHub Pages.

---

## Project Goals

This project aims to:

- Practice semantic HTML structure.
- Improve CSS layout skills using Flexbox and CSS Grid.
- Build responsive layouts for different screen sizes.
- Write clean, maintainable, and reusable code.
- Follow modern front-end development practices.
- Create a strong portfolio project that grows alongside my learning journey.

---

## Current Tech Stack

- HTML5
- CSS

No frameworks or libraries are used at this stage in order to strengthen my understanding of core web technologies.

---

## Deployment

The first static version of the website will be deployed using GitHub Pages.
