# AI Usage Report

**Student:** Yigitcan Yesilyurt

**Project:** HTML & CSS final project

**Purpose:** To document how ChatGPT has been used during the learning process.

---

## Overview

Throughout the project, ChatGPT has primarily been used as a technical mentor, reviewer, and learning resource rather than as a tool for generating complete assignments.

The conversations have focused on understanding web development concepts, reviewing completed work, improving code quality, and discussing professional software development practices.

---

## Primary Uses of AI

### 1. Code Review

The most frequent use of ChatGPT has been reviewing completed HTML and CSS implementations.

Typical requests include:

- Reviewing semantic HTML structure
- Evaluating CSS architecture
- Checking responsive layouts
- Identifying maintainability issues
- Reviewing accessibility
- Assessing project organization
- Providing professional code review feedback

The feedback is typically requested using severity levels such as:

- Blocking
- Major
- Minor
- Suggestion

rather than simply asking whether the code is "good."

---

### 2. Learning Concepts

A significant portion of the conversations focuses on understanding concepts before implementation.

Examples include:

- Flexbox
- CSS Grid
- Responsive Design
- Semantic HTML
- Accessibility
- CSS Variables
- Layout strategies
- Component architecture
- Naming conventions

The discussions usually emphasize _why_ something works rather than simply _what_ code should be written.

---

### 3. Project Architecture

Many conversations involve planning larger technical decisions instead of individual code snippets.

Topics include:

- Folder structure
- CSS organization
- Reusable templates
- Documentation
- Scalability
- Maintainability
- Long-term project structure

---

### 4. Debugging

When problems occur, the usual workflow is:

1. Present the existing implementation.
2. Explain the observed issue.
3. Investigate possible causes.
4. Identify the root cause.
5. Discuss appropriate solutions.

The focus is generally on understanding the problem instead of immediately replacing the code with a complete solution.

---

### 5. Documentation

ChatGPT has also been used to improve project documentation, including:

- README files
- Project descriptions
- Development notes
- Checklists
- Coding guidelines
- Learning documentation

---

## Frequency of Use

ChatGPT has been used regularly throughout the bootcamp.

Most sessions consist of multiple technical discussions covering:

- Concept explanations
- Code reviews
- Debugging
- Architecture discussions
- Best practices
- Documentation

The interaction style is typically iterative rather than consisting of isolated questions.

---

## Nature of the Assistance

The assistance generally falls into the following categories:

- Explaining technical concepts
- Reviewing existing code
- Identifying implementation issues
- Suggesting improvements
- Discussing architecture
- Explaining best practices
- Helping create documentation

While complete examples are sometimes requested, the majority of conversations revolve around reviewing, refining, or understanding existing work.

---

## Working Style Observed

Based on the conversation history, the student commonly:

- Writes code independently before requesting feedback.
- Requests detailed reviews rather than simple approval.
- Asks why one approach is preferable to another.
- Revisits previous architectural decisions.
- Iteratively improves existing implementations.
- Prioritizes understanding over copying solutions.

Many discussions involve comparing different approaches and evaluating trade-offs instead of simply producing working code.

---

## Limitations

This report is based solely on conversations available within ChatGPT.

It **cannot** determine:

- Which parts of submitted assignments were completed without AI.
- Whether AI tools outside of ChatGPT were used.
- How much implementation work was completed independently outside these conversations.

Accordingly, this report describes the nature of the conversations rather than making claims about authorship.

---

## Overall Assessment

Based on the available conversations, ChatGPT has primarily been used as a learning companion, technical mentor, reviewer, and reference.

The interactions are largely focused on improving understanding, code quality, maintainability, and professional frontend development practices rather than generating complete assignments.

The conversation history suggests that AI has been integrated into the student's learning process as a tool for explanation, review, and iterative improvement rather than as a replacement for the student's own implementation work.

This report reflects only the conversations available to ChatGPT. It should not be interpreted as proof of authorship or proof that any particular assignment was completed independently.
